01

Docubot

AI Agent · Transport Sector · Production

Agente IA · Sector Transporte · En Producción

Modular AI chatbot ecosystem that automates legal document processing for Colombia's transport sector via WhatsApp. Integrates directly with the Ministry of Transport's systems to issue official documents on behalf of users. Built with a microservices architecture: Go/Gin API, Rasa NLP engine, Node.js + Baileys WhatsApp gateway, Playwright browser automation, and a Vue 3 admin dashboard.

Ecosistema de chatbot IA modular que automatiza la expedición de documentos legales para el sector transporte de Colombia vía WhatsApp. Se integra directamente con los sistemas del Ministerio de Transporte para expedir documentos oficiales. Arquitectura de microservicios: API Go/Gin, motor NLP Rasa, gateway WhatsApp con Node.js + Baileys, automatización web con Playwright y panel administrativo Vue 3.
